                    Google Cloud & Minimalist UX Review
                    
5 Key Improvements Over v2.0.9

                

                
            


            

                

                    
1. Natural Language Config Bar (Minimalist Mode)

                    
Replaces two bulky configuration panels with a single concise sentence: Extract from [Details] using [Key=Value] split by [¦] and [:], tucking secondary options under a clean Rules popover.

                

                

                    
2. Click-to-Rename Merged Column (Minimalist Mode)

                    
In 90% of cases, users keep the original key name. Merging Key and New name removes 13 redundant text inputs; simply click any column name to rename it inline.

                

                

                    
3. Smart Bulk Selection (⚡ ≥50% Rate Pill)

                    
Log payloads often produce dozens of sparse keys (<10% rate). Adding a 1-click ≥50% Rate filter saves data engineers from manually unchecking noisy tail fields.

                

                

                    
4. Real-Time SQL Schema Guardrails

                    
When a user renames two columns to the same identifier, the input immediately highlights in red and disables the Apply button before a broken SQL query can be executed.

                

                

                    
5. Action-Oriented Primary CTA (Apply Count Badge)

                    
Showing the exact count of selected columns inside the Apply (13) button gives clear confirmation of how many new columns will be materialized.
