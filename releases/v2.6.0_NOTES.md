### Key Highlights & Summary

TOAD v2.6.0 completes the P0 + P1 architectural, performance, and security upgrade across the standalone Electron desktop runtime and Rust native engine (`toad-core` v2.6.0), unifying DuckDB and Ledger ownership inside a single supervised `utilityProcess`, introducing an O(1) append-only JSONL Write-Ahead Log (`toad_ledger.wal.jsonl`) with self-healing Parquet compaction and persistent derived views (`_rx*`), shipping an in-process `napi-rs` native addon (`toad_core.node`) with Control Flow Guard (`/guard:cf`), adding transparent Gzip (`.csv.gz`, `.tsv.gz`, `.jsonl.gz`) and streaming UTF-16LE/BE support, hardening Electron Fuses (`01000101`), and reducing `app.asar` package entries below 1,000 files.

#### 1. Unified Single-Engine Architecture & Crash Resilience (`utilityProcess`)
- **Single-Brain Engine Ownership:** Consolidated all DuckDB interactive queries, background ingestion, and `ToadParquetLedger` state operations inside the dedicated `EngineService` (`utilityProcess`), eliminating Main-vs-Utility split-brain contention.
- **Race-Free `MessagePort` & Hybrid Wire Protocol:** Propagates late `MessagePort` bindings across active `RemoteDataSourceConnection` instances, preserves `MessagePort` transport across SQL/application errors without degrading to fallback IPC, and supports both vectorized Apache Arrow IPC streams and zero-copy `'TOAD'` Hybrid v1 frames.
- **Sub-500ms Crash Auto-Recovery & Derived View Replay:** `EngineSupervisor` automatically respawns crashed engine workers within `< 500ms` and deterministically replays both base Parquet views and chained Regex/KV derived views (`_rx*`).

#### 2. Append-Only JSONL WAL, Self-Healing Ledger & Worker Config Parity
- **O(1) Hot-Tier WAL + Cold-Tier Parquet Compaction:** High-frequency ingestion events append to `toad_ledger.wal.jsonl` in `< 0.5ms` and automatically compact into `toad_ledger.parquet` at threshold or shutdown, eliminating $O(N^2)$ full-file rewrites.
- **Corrupt Ledger Self-Healing (`GG.11`):** Recovers cleanly from corrupted or 0-byte `toad_ledger.parquet` files on isolated DuckDB connections while quarantining non-empty damaged ledgers before reconstruction.
- **Supervised Out-of-Process Ingest Workers:** Normalizes camelCase and snake_case worker settings (`rowGroupSize`, `maxMemory`, `threads`, `compression`) and spawns workers via `EngineSupervisor` without `ELECTRON_RUN_AS_NODE`.

#### 3. Dual-Target Native Rust Core (`toad_core.node` + `toad-core.exe`), `.gz` & UTF-16 Support
- **In-Process `napi-rs` FFI Addon:** Added `bin/toad_core.node` alongside backward-compatible `bin/toad-core.exe` CLI for zero-spawn Binary Guard inspection, encoding detection, streaming transcoding, EVTX parsing, and Windows process I/O telemetry, compiled with MSVC `/guard:cf` (`GUARD_CF`).
- **Gzip & Multi-Member UTF-16LE/BE Streaming:** Supports `.csv.gz`, `.tsv.gz`, and `.jsonl.gz` (including concatenated multi-member archives while blocking disguised gzipped PE binaries) and transcodes UTF-16LE/BE logs in 64 KB chunks without splitting surrogate pairs across chunk boundaries.

#### 4. Security Hardening, ASAR Diet (`< 1,000` Entries) & Zero-Duplicate Packaging
- **IPC & Shell Hardening:** Eliminated PowerShell command injection in EVTX fallback paths via parameterized `execFile` + environment variable binding, enforced strict `http:`/`https:` allowlists on `openExternal`, enabled `contextIsolation: true` / `nodeIntegration: false` on QuickStart windows, and added sandboxed clipboard IPC handlers.
- **Electron Fuse Hardening (`01000101`):** Disabled `RunAsNode`, `EnableNodeOptionsEnvironmentVariable`, and `EnableNodeCliInspectArguments`; enabled `EnableCookieEncryption` and `OnlyLoadAppFromAsar`.
- **ASAR Diet & Deterministic Smoke Gate:** Pruned build-only/modular bloat in `app.asar` from 3,694 entries down to 915 entries (10.63 MB, `< 1,000` target) while preserving `lodash`, `duckdb.node`, `@mapbox/node-pre-gyp`, and `@apache-arrow/es2015-cjs`, verified via `Toad.exe --smoke-check`.
