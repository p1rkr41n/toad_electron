# Toad v2.4.7 Release Notes

**Release Date:** 2026-11-03  
**Binary Output:** `Toad-2.4.7-x64-portable.exe` & `Toad-2.4.7-x64-portable.zip`

---

## Highlights & Bugfixes

### 1. Gateway Cache Validation & Stale Parquet Eviction
- Moved and enhanced `isMisparsedDelimiter` schema check into `checkDoubleValidCache` before `createViewFromParquet` in `reltab-fs.ts`.
- Automatically evicts stale or misparsed Parquet cache files (where Column 0 contains commas or synthetic `column01..columnN` columns exist) immediately upon opening a file from the project sidebar.
- Purged orphan `.tmp_` Parquet files left by abrupt shutdowns.

### 2. RFC-4180 CSV Parser Stabilization
- Enforced `delim = ','` for CSV imports, avoiding CSV sniffer confusion caused by dense pipe (`|`) characters in script blocks.
- Removed `escape = ''` to restore RFC-4180 compliant double-quote escaping (`""`), correctly handling multiline and quote-heavy PowerShell ScriptBlock logs without premature column termination.
- Maintained `all_varchar = true` to permanently prevent DuckDB native C++ assertion crashes (`vector.cpp:1859`).

### 3. Non-Blocking Ingestion Error Handling & Status Badging
- Suppressed intrusive modal popup error dialogs when an ingestion or parsing error occurs.
- Automatically writes full error tracebacks to `toad.log`.
- Displays an exclamation mark circle badge (`!`) on the project sidebar/table for failed files.
