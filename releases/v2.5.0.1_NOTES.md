### Summary of Changes

TOAD v2.5.0.1 addresses the capability denial security error encountered when loading projects containing multiple data files (e.g. `.log`, `.csv`, `.evtx`).

#### 1. Security Whitelist & Reltab Database RPC Resolution
- **Root Cause:** In v2.5.0, `preload.js` enforced a strict capability whitelist which omitted the explicit Reltab remote RPC methods (`DataSourceConnection.getTableName`, `evalQuery`, `rowCount`, `getTableSchema`, `getColumnStatsMap`, `getRootNode`, `getChildren`, `runSqlQuery`, `runSqlQueryArrow`, `dispose`).
- **Fix:** Enumerated all explicit `DataSourceConnection.*` RPC methods, unprefixed short aliases, and engine handshake channels (`engine:request-port`, `engine:restored`, `toad-engine-port`, `getDataSources`) in `STRICT_CAPABILITIES_WHITELIST` / `STRICT_CAPABILITIES_SET`.
- **Zero-Trust Hardening:** Eliminated loose `cmd.startsWith("DataSourceConnection.")` wildcard check to prevent arbitrary unauthorized channel invocations while permitting legitimate data operations.

#### 2. Bidirectional Command Aliasing & Server Dispatch
- Synchronized `COMMAND_ALIAS_MAP` in `tad-master/packages/toad-app/app/preload.js` and `tad-master/packages/host-bridge/src/commandAliases.ts`.
- Enhanced `ElectronTransportServer` in `main.ts` to automatically register bidirectional handlers for both fully-qualified and short method names.

#### 3. Comprehensive Verification & Zero-Cost Pipeline
- Added `SUITE CC.1b: Preload Strict Security Gate 100% RPC Matrix Verification (Zero-Trust)` in `tests/deep_integration_qa.js`.
- Passed 100% of the entire automated test suite:
  - Smoke Test (v2.5.0.1)
  - Apache Arrow IPC & `invokeBinary` (13 Tests)
  - Deep Integration QA (223 Tests)
  - Preload 3 Pages & Dynamic PageSize (10 Tests)
  - Legacy Use Cases (19 Tests)
- Packaged portable binary with strict footprint compliance:
  - `app.asar`: **28.06 MB** (Budget < 45.0 MB)
  - `Toad-2.5.0.1-x64-portable.exe`: **72.36 MB** (Budget < 75.0 MB)
  - Canonical `Toad.exe` in workspace root.
  - Zero-duplicate binary policy maintained.
