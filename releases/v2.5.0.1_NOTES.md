### Tóm Tắt Điểm Nổi Bật

Bản phát hành TOAD v2.5.0.1 khắc phục lỗi chặn nạp tệp dữ liệu, hoàn thiện cổng bảo mật Zero-Trust và tích hợp giao thức nhị phân Apache Arrow IPC Stream tốc độ cao.

#### 1. Sửa Lỗi Bảo Mật Preload & Khai Báo Toàn Diện Reltab RPC
- **Xử lý triệt để lỗi chặn file:** Khắc phục lỗi `[SecurityError: Capability Denied]` khi mở project chứa nhiều định dạng (`.log`, `.csv`, `.evtx`).
- **Bổ sung 10 phương thức RPC cốt lõi:** Khai báo tường minh toàn bộ các hàm `DataSourceConnection.*` (`getTableName`, `evalQuery`, `rowCount`, `getTableSchema`, `runSqlQuery`, `runSqlQueryArrow`, v.v.) và kênh engine handshake vào `STRICT_CAPABILITIES_WHITELIST`.
- **Cơ chế Zero-Trust tuyệt đối:** Loại bỏ kiểm tra wildcard lỏng lẻo (`startsWith`), thay thế bằng `Set` tra cứu chính xác $O(1)$ ngăn chặn mọi lệnh trái phép.

#### 2. Đồng Bộ Hóa Kiến Trúc Tauri-Like & Giao Thức Apache Arrow IPC
- **Chuẩn hóa API Host Bridge:** Hoàn thiện `toadBridge.invoke()`, `invokeBinary()`, `listen()`, `emit()` tương thích 100% mô hình Tauri v2.
- **Truyền tải nhị phân Zero-Copy:** Tích hợp Apache Arrow IPC Stream cho kết quả truy vấn DuckDB, tăng tốc độ render bảng dữ liệu lớn gấp 3–5 lần so với JSON tuần tự.
- **Tương thích 2 chiều:** Đăng ký alias song song cả tên ngắn lẫn tên đầy đủ trên IPC Main Process.

#### 3. Kiểm Thử Nghiêm Ngặt & Tối Ưu Hóa Kích Thước
- **Đạt chuẩn kiểm thử 100%:** Vượt qua toàn bộ **268/268 bài test tự động** (bao gồm 15 bài Arrow IPC, 223 bài QA tích hợp sâu, và kiểm tra tải 10.000 dòng).
- **Dung lượng siêu gọn:** `app.asar` đạt **28.06 MB** (ngân sách < 45 MB), file portable exe chỉ **72.36 MB** (ngân sách < 75 MB).
