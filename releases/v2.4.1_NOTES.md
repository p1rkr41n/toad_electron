## Toad v2.4.1 - Data-Dense Dashboard Sidebar & Hover Ergonomics Release

### 🌟 Key Enhancements & UI/UX Redesign

1. **Data-Dense Dashboard Sidebar**:
   - **Zero Collision Single-Row Tree Layout**: Re-engineered Blueprint.js Tree rows into strict 30px single-row flex layouts (`height: 30px !important`). Eliminates vertical content overflowing and text collision between project and child rows.
   - **Progressive Disclosure Hover Actions**: Project administration buttons (`[+] Add File`, `[📂] Add Folder`, `[🧹] Purge Cache`, `[🗑️] Delete`) are sleek icon-only actions that smoothly fade in on row hover (`.project-hover-actions`: `opacity: 0` -> `opacity: 1`), keeping the view clean and distraction-free when browsing.
   - **Desktop IDE Right-Click Context Menu**: Added native Blueprint Context Menu on project nodes with options to add files, add directories, purge parquet caches, or delete projects.

2. **75% File Name Width Recovery**:
   - Replaced bulky boxy `[READY]` badges with compact **Status Dot indicators** (`🟢 Ready`, `🔴 [MODIFIED]`, circular micro-spinner for processing) and subtle tabular row counts (`37.2K`, `62.3M`).
   - Maximized file name horizontal space by up to **75-80%**, preventing truncation of long forensic and system log file names.
   - Rich hover tooltip card displaying full disk path, original file size, formatted row count, and cache status.

3. **Zero Legacy Root Redundancy**:
   - Completely removed `legacyRootNodes` duplication from `treeState`. All files and directories strictly belong to their assigned projects.
   - Virtual `orphan_prj` features an inline header action `[↳ Move all]` to seamlessly merge all legacy files into `Untitled-1` in a single click.

4. **Streamlined Workspace Toolbar**:
   - Compact dashboard header with uppercase `PROJECTS` category label, minimal quick actions (`[➕ New Project]`, `[🔄 Refresh]`, `[🧹 Clear All Cache]`), and an integrated search input with quick clear button.

5. **100% Automated QA Coverage**:
   - Verified with comprehensive test suite (`tests/deep_integration_qa.js`) covering layout constraints, zero redundancy, status dot ergonomics, context menu triggers, and system-wide v2.4.1 synchronization.
