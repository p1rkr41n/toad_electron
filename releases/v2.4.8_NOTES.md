## TOAD v2.4.8 Full Rebrand & Architecture Modernization

TOAD v2.4.8 marks the complete brand transformation from TAD (Tabular Analysis Desktop) to **TOAD** (**Tabular OLAP Analytics Desktop**), incorporating comprehensive monorepo renames, asset synchronization, DuckDB SQL engine isolation, and lossless backward compatibility for existing user workspaces.

---

## Key Highlights & Architectural Enhancements

### 1. Monorepo Package Renaming & Modularization
- Renamed `tad-master/packages/tad-app` -> `tad-master/packages/toad-app`.
- Renamed `tad-master/packages/tadviewer` -> `tad-master/packages/toadviewer`.
- Synchronized all internal TypeScript imports and package manifest dependencies across the entire monorepo from `tadviewer` to `toadviewer`.
- Provided seamless backward compatibility wrappers (`tadviewer.js`, `tadviewer.less`) ensuring legacy third-party scripts continue functioning without disruption.

### 2. Webpack Bundle & Asset Synchronization
- Renderer entry point bundle renamed to `toadapp.bundle.js` with optimized production bundling (`devtool: false`).
- Application entry HTML (`index.html`) updated to reference `<script src="toadapp.bundle.js"></script>`, eliminating blank-screen launch exceptions.
- Maintained electron-builder asar packaging rule (`!**/node_modules/toadviewer/**`), keeping the `app.asar` footprint strictly below 45 MB (~39 MB).

### 3. Transparent File Format Compatibility (.toad & .tad)
- Upgraded the default file format to `.toad` with `toadFileFormatVersion: 2`.
- Transparent backward compatibility loader allows opening and analyzing legacy `.tad` workspace files (`tadFileFormatVersion: 1`) without errors.
- Automatically handles schema migration from legacy `targetPath` to `DataSourcePath`.
- System Open and Save dialogs prioritize `.toad` while maintaining full support for `.tad` files.

### 4. DuckDB SQL Isolation & UI Branding
- RelTab DuckDB engine updated to generate temporary query views with the `toad_tmpView_${counter}` namespace prefix, preventing query collision and metadata leakage.
- Modernized UI container classes to `.toad-app-pane` and unified query error dispatching under `toad-query-error`.
- Application titlebar dynamically branded to `<File/Project> - TOAD` and About dialog updated to `TOAD - Tabular OLAP Analytics Desktop (v2.4.8)`.

### 5. FastBuild Engine & Zero-Duplicate Binary Packaging
- FastBuild engine verified for ultra-fast unpacked build generation (`build/Toad-2.4.8/Toad.exe`).
- Zero-Duplicate Binary Storage policy strictly enforced: pruned legacy duplicate versioned binaries, delivering single canonical root executable `Toad.exe` and release executable `releases/Toad-2.4.8-x64-portable.exe` (< 75 MB).
- High-efficiency compressed portable zip archive (`Toad-2.4.8-x64-portable.zip`), SHA-256 cryptographic verification ledger (`SHA256SUMS.txt`), and Microsoft Winget distribution manifest (`HelloKittyXamKinLung.Toad.yaml`).
