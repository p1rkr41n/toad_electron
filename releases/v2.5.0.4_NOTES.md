### Key Highlights & Summary

TOAD v2.5.0.4 introduces a 1-click context menu shortcut to extract structured data from JSON and semi-structured text directly from DataGrid cells, integrates an automated test suite for nested JSON and dotted keys, and verifies out-of-core streaming performance on 40GB datasets.

#### 1. 1-Click Context Menu Column Extraction
- **Cell Context Menu Shortcut:** Right-clicking on any table cell reveals the `Parse / Extract "<colName>"...` action (with Blueprint `derive-column` icon).
- **Auto-Target & Auto-Detect:** Automatically pre-selects the clicked column in the Parse/Split Dialog and detects JSON objects (`{...}`) or arrays (`[...]`), instantly setting the extractor format to JSON without manual configuration.

#### 2. Nested JSON & Dotted-Key Automated Test Suite
- **Dedicated CI/QA Suite:** Added `tests/test_nested_json.js` covering DuckDB `STRUCT`, `LIST/ARRAY`, JSONPath extraction (`json_extract_string`), and Unicode-delimited Key-Value logs (Hayabusa).
- **Dotted Field Isolation:** Verified that dotted literal keys (`"target.host"`) and struct sub-fields (`target.host`) coexist without collision or schema corruption.

#### 3. Out-of-Core 40GB Large Dataset Ingestion
- **Instant Metadata Sampling:** Verified out-of-core streaming across 40GB datasets (`sample_40gb.csv` in 586ms, `sample_40gb.json` in 1.8s) with zero memory bloat and robust column inference.

#### 4. Footprint & Single-Binary Integrity
- **Optimized Size:** Portable binary packaged at ~72.4 MB with `app.asar` footprint under 29 MB.
- **Zero-Duplicate Policy:** Strict deduplication enforced across release artifacts and local development binaries.
