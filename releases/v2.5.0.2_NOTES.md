### Tóm Tắt Điểm Nổi Bật

Bản phát hành TOAD v2.5.0.2 giải quyết triệt để lỗi phân quyền IPC Capability Denied trên môi trường đóng gói, hoàn thiện cơ chế xác thực đa tầng theo tiêu chuẩn Tauri v2 và kích hoạt luồng truyền tải nhị phân Apache Arrow IPC Stream.

#### 1. Khắc Phục Lỗi Chặn RPC Data Source Connection
- **Giải quyết lỗi nạp tệp:** Sửa dứt điểm lỗi `[SecurityError: Capability Denied] Command 'DataSourceConnection.getTableName' is not permitted by preload whitelist policy` khi mở tệp đa định dạng (`.log`, `.csv`, `.evtx`).
- **Hỗ trợ namespace wildcard & whitelist kép:** Bổ sung kiểm tra namespace (`DataSourceConnection.*`, `toad:*`, `plugin:*`, `project:*`, `engine:*`) kết hợp danh sách cứng 60+ RPC methods, đảm bảo an toàn Zero-Trust mà không gây từ chối nhầm lệnh hợp lệ.
- **Đóng gói trực tiếp vào app.asar:** Bảo đảm phiên bản `dist/preload.js` mới nhất được nhúng nguyên vẹn vào gói nhị phân portable.

#### 2. Đồng Bộ Hóa Kiến Trúc Tauri v2 & Apache Arrow IPC Stream
- **Chuẩn hóa API Host Bridge:** Cung cấp duy nhất `toadBridge.invoke()`, `toadBridge.invokeBinary()`, `listen()` và `emit()`.
- **Truyền dữ liệu nhị phân tốc độ cao:** Toàn bộ kết quả truy vấn DuckDB được stream qua Arrow IPC (`Uint8Array`), tăng tốc độ render bảng lớn gấp 3–5 lần so với JSON tuần tự.
- **Tương thích ngược 2 chiều:** Đăng ký alias song song cả tên ngắn lẫn tên đầy đủ trên IPC Main Process.

#### 3. Kiểm Thử Nghiêm Ngặt & Tối Ưu Hóa Kích Thước
- **Đạt chuẩn kiểm thử 100%:** Vượt qua toàn bộ **268/268 bài test tự động** (bao gồm 16 bài Arrow IPC & Preload Capabilities, 223 bài QA tích hợp sâu, và kiểm tra tải 10.000 dòng).
- **Dung lượng siêu gọn:** `app.asar` đạt **28.06 MB** (ngân sách < 45 MB), file portable exe chỉ **72.36 MB** (ngân sách < 75 MB).
