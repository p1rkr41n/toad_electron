## Toad v2.3.4 - ASAR Sealing & Zero-Crash Resilience Release

### 🌟 Key Enhancements & Fixes

1. **ASAR Sealing (`asarUnpack` Hardening)**:
   - **Root Cause Rectification**: Removed `**/*reltab*` from `asarUnpack` in `tad-app/package.json`. Core JS libraries (`reltab`, `reltab-duckdb`, `reltab-fs`) are now 100% sealed inside the immutable `app.asar` archive.

2. **Shutdown File Handle Buffer**:
   - Extended graceful shutdown release window to 150ms in `before-quit` to ensure Windows kernel memory mappings and active DuckDB streams fully detach before portable NSIS wrapper triggers directory cleanup.

3. **100% Automated QA Test Coverage**:
