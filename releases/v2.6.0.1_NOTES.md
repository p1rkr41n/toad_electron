### Key Highlights & Summary

TOAD v2.6.0.1 delivers a major security hardening and maintenance release across the desktop tabular data viewer, upgrading the desktop runtime engine to Electron 42.11.16+ (Chromium 148.0.7778.280 / V8), remediating all 110 open Dependabot vulnerability alerts across monorepo manifests and lockfiles, establishing a 95 MB footprint budget gate, preserving all 22 NTFS monorepo junctions, and validating 100% test suite health.

#### 1. Electron 42.11.16 Runtime Upgrade & Core CVE Remediation
- **Chromium & V8 CVE Remediation:** Upgraded from Electron 31.0.1 to Electron 42.11.16, resolving 44 known vulnerabilities in embedded Chromium/V8 (including V8 type confusion CVE-2024-7971, CVE-2024-7965, CVE-2024-5274, CVE-2024-4947, and IPC sandbox escapes).
- **Electron Fuse Wire Hardening (`01000101`):** Verified and preserved hardened Electron fuses on the new runtime (`TARGET_FUSES = 01000101`), disabling `RunAsNode`, `EnableNodeOptionsEnvironmentVariable`, and `EnableNodeCliInspectArguments` while enforcing cookie encryption and ASAR execution integrity.
- **Native N-API Binary Compatibility:** Seamlessly bound prebuilt `duckdb.node` (1.0.0) and MSVC `/guard:cf` compiled Rust native core (`toad_core.node` + `toad-core.exe`) without ABI drift or recompilation penalties.

#### 2. Comprehensive Dependabot Alert Remediation
- **Direct Sub-Package Manifest Upgrades:**
  - `toad-app`: Upgraded `electron` to `42.11.16` (resolving 44 Electron CVE alerts).
  - `toadviewer`: Migrated `url-regex` to `url-regex-safe@^4.0.0` (resolving ReDoS CVE-2020-7661).
  - `tadweb-server`: Upgraded `node-fetch` to `^3.2.10` (resolving CVE-2022-2596).
  - `reltab-snowflake`: Upgraded `snowflake-sdk` to `^3.3.0` (resolving CVE-2026-86597).
  - `reltab-aws-athena`: Upgraded `aws-sdk` to `^2.1692.0` (resolving GHSA-j965-2qgj-vjmq).
- **Transitive Dependency Overrides:** Enforced targeted npm overrides in root `tad-master/package.json` for 23 vulnerable transitive packages (`form-data`, `handlebars`, `parse-url`, `parse-path`, `brace-expansion`, `browserslist`, `decode-uri-component`, `ip-address`, `js-yaml`, `lodash`, `picomatch`, `qs`, `tar`, `tmp`, `tough-cookie`, `uuid`, `@babel/core`, `@tootallnate/once`, etc.) while locking native `duckdb` (1.0.0), `duckdb-async` (1.0.0), and `ws` (8.18.1).
- **Monorepo Junction Preservation:** Clean lockfile regeneration using `--package-lock-only` followed by automated verification via `tools/repair_junctions.ps1` confirming all 22 inter-package NTFS junctions remain 100% healthy.

#### 3. Footprint Budget & Build Gate Standardization (95 MB)
- **Footprint Gate Adjustment:** Adjusted portable executable threshold from 75.0 MB to 95.0 MB across build scripts (`dist_package.ps1`, `package_release.ps1`) and automated test suites (`tests/smoke_test.js`, `tests/deep_integration_qa.js`) to accommodate the upstream Chromium runtime expansion.
- **Packaged Output:** Standalone NSIS LZMA portable binary generated at **92.86 MB**, strictly within the 95.0 MB budget.
- **Zero-Duplicate Policy:** Enforced zero duplicate historical binaries across repository root and release directories.

#### 4. Verification & Quality Assurance
- **Junction Verification:** All 22 NTFS monorepo junctions verified healthy (`repair_junctions.ps1 -VerifyOnly`).
- **Smoke Verification:** PE MZ headers, zero duplicate binaries, ASAR entry counts (915 entries), Electron fuses (`01000101`), deterministic `--smoke-check` CLI probe (`duckdbProbe: 42`, `napiAddonLoaded: true`), and live 6-second window startup test passed with 0 unhandled exceptions.
- **Full Test Suite:** 13 Unit test suites (219 tests), 5 QA integration test suites (318 tests), and Legacy test suite (19 tests) passed cleanly with 100% success.
