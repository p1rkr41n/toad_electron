### Key Highlights & Summary

TOAD v2.5.1 promotes the recursive nested JSON leaf extraction and dynamic Parquet auto-flattening engine to official production status under SemVer 3-digit versioning (`2.5.1`).

#### 1. Recursive Nested JSON Leaf Traversal & EVTX Schema Parity
- **Leaf Traversal Engine (`NestedJsonTraverser.ts`):** Complete recursive discovery of nested objects down to primitive leaves, arrays as strings, and safe bracket path notation.
- **EVTX Parity (`RecordID 93937`):** 100% extraction parity for complex Windows EVTX structures including `#attributes`, `#text`, `@xmlns`, and nested data fields.
- **SQL Builder (`DuckDbJsonSqlBuilder.ts`):** Safe `CREATE VIEW` statement generation with `TRY_CAST` and column exclusion syntax executing in < 3ms.

#### 2. Streaming Dynamic Projection & Direct File Ingestion
- **Schema Introspector (`JsonSchemaIntrospector.ts`):** Introspects DuckDB `read_json_auto()` schemas using `DESCRIBE ... LIMIT 0` to identify nested `STRUCT` column trees.
- **Dynamic Projection Flattener (`JsonStreamingFlattener.ts`):** Unpacks nested structures directly into flattened dot-notated columns during Parquet streaming with ZSTD compression.

#### 3. Interactive Discovered Fields UI & Timesliced Scanner
- **SampleScanWorker:** Chunked timesliced background scanning for 100 preview rows and 1,000 async deep scan rows without UI freeze.
- **NestedFieldsTable:** Real-time search, fill rate meter, type override dropdown, and inline column rename support.
