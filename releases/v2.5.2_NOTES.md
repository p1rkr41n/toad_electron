### Key Highlights & Summary

TOAD v2.5.2 delivers an asynchronous query execution lifecycle for the Filter Editor, intelligent N-line cell text wrapping across all tabular surfaces, refined Parse Columns UX, active cell glow suppression behind modals, and core forensic ingestion streaming engines.

#### 1. Filter Editor Asynchronous 3-Phase Apply Lifecycle
- **Query Completion Synchronization:** Replaced premature synchronous state transitions with an asynchronous 3-phase state machine (`idle` ➔ `applying` ➔ `applied`).
- **Applying Phase:** Displays `Applying...` with an inline `<Spinner size={12} intent={Intent.PRIMARY} />`, disables the button against double submissions, and switches cursor to `wait`.
- **Applied Phase:** Transitions to `Applied! ✔` (`bp4-intent-success is-applied`) only when DuckDB query resolves and `appState.viewState.queryView` is updated. Automatically reverts to `idle` after 1.8s.
- **Error Guard & Fast-Path:** Cancels `applying` immediately on DuckDB error without showing `Applied! ✔`; provides instant fast-path for re-applying identical queries.

#### 2. Intelligent Dynamic Cell Wrap Across All Tabular Views
- **Smart Line Calculation (`CellLineCalculator.ts`):** Dynamic line mapping contract across Sidebar Files Table, Main DataGrid, and Parse Dialog Nested Fields Table.
  - $N \le 1$ lines: Standard flat row ($24\text{px} - 25\text{px}$), no scroll, no popup.
  - $2 \le N \le 5$ lines: Automatically expands to fit exact content ($H = N \times 17\text{px} + 8\text{px}$).
  - $N > 5$ lines: Capped at 5 lines ($H \approx 93\text{px} - 95\text{px}$) with a smooth 4px slim scrollbar.
- **4-Way Dismissal:** Click same cell, click another cell, click outside grid, or press `Escape`.

#### 3. Streamlined Parse Columns Dialog UX
- **Consolidated Format Selector:** Added `Nested JSON` directly to the `#minFormatSelect` dropdown; removed redundant top tab `#ntab-nested` and `#btn-switch-nested` button.
- **Clean Mode Transition:** Selecting `Nested JSON` activates recursive leaf extraction and field scan; selecting other formats reverts to standard visual view.

#### 4. Modal Background Active Cell Glow Suppression
- **Clean Modal Backdrop:** Suppressed `.slick-cell.active`, `.slick-row.active`, and `.slick-cell.selected` highlights when `body.bp4-overlay-open` is active.
- **Event Dismantling:** Dispatches `dismiss-grid-cell-expand` via `GridOverlayBus` and invokes `grid.resetActiveCell()` on modal open.

#### 5. Forensic Ingestion Engines (Milestone 5)
- **RFC-4180 CSV/TSV Sniffer:** Delimiter auto-detection, schema verification, and `all_varchar = true` assertion protection.
- **Rust SIMD EVTX Decoder:** High-speed Windows Event Log binary decoding into structured JSONL/Parquet.
- **SJF Ingestion Scheduler:** Shortest-job-first scheduling with concurrency throttling and VIP jump-to-front preemption.
