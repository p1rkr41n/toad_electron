# Toad v2.4.6 Release Notes

## Consistent Multi-Stage CSV Ingestion, Corrupted Cache Auto-Eviction & Automatic Header Detection in Parse Dialog

### Overview
Toad v2.4.6 delivers universal, consistent CSV ingestion across all dataset types (standard spreadsheets, MFTECmd $MFT dumps, Hayabusa timelines, KAPE artifacts, and security logs). It eliminates the legacy behavior where complex CSVs unexpectedly compressed into a single `raw_event` column, introduces automatic cache eviction for stale 1-column Parquet caches, and upgrades the Parse Columns dialog with intelligent first-row header detection.

### Core Architectural Upgrades

1. **Multi-Stage Defensive CSV Fallback Pipeline (`csvimport.ts` & `ingestWorker.ts`)**:
   - For all complex and forensic CSV files (`isComplexLogFile(filePath) === true`), Toad implements a two-stage ingest strategy:
     - **Stage 1 (Safe Profile)**: Streams via `auto_detect = true, sample_size = 100000, ignore_errors = true, null_padding = true, parallel = false, all_varchar = true, delim = ',', quote = '"', escape = ''`.
     - **Stage 2 (Force Header Fallback)**: If DuckDB's sniffer encounters wide paths, odd quotes, or irregular lines, Toad immediately switches to Stage 2: `header = true, delim = ',', quote = '"', escape = '', ignore_errors = true, null_padding = true, parallel = false, all_varchar = true`.
     - This forces DuckDB to read the exact first row as the schema headers, guaranteeing 100% column preservation (e.g. 25+ columns for MFTECmd $MFT dumps: `EntryNumber`, `InUse`, `ParentEntryNumber`, `OSPath`, `FileName`, `FileSize`, etc.).
     - Prevents any valid `.csv` file from being collapsed into a single `raw_event` column.

2. **Automatic Corrupted Cache Eviction (`checkDoubleValidCache`)**:
   - Detects stale or corrupted 1-column `raw_event` Parquet caches for `.csv` files.
   - Automatically invalidates and evicts the outdated single-column cache and triggers a fresh multi-stage ingestion, immediately restoring the full multi-column schema without requiring manual cache purges.

3. **Intelligent "First Row Contains Headers" in Parse Columns Dialog (`RegexDialog.tsx`)**:
   - Adds an intelligent first-row header detection algorithm for CSV delimiter parsing:
     - Automatically inspects row 1 (`samplesToScan[0]`); if it represents textual column headers (e.g. `EntryNumber,InUse,ParentEntryNumber`), Toad enables `First row contains headers`.
     - Directly populates `outputColName` with the actual header names instead of generic `str001`, `str002`, `str003`.
     - Automatically selects sample values (`sampleVal`) from row 2 (actual data).
     - Automatically injects SQL view filters (`WHERE "${targetCol}" NOT LIKE '${headerPattern}%'`) to exclude the legacy header row from query results.
     - Adds user-controllable Blueprint checkbox `<Checkbox checked={firstRowIsHeader} label="First row contains column headers" />`.

4. **Deep Integration QA SUITE MM**:
   - Added `SUITE MM` (MM.1 through MM.5) in `tests/deep_integration_qa.js`.
   - Verifies 25+ column MFTECmd CSV parsing, Stage 2 Force Header resilience, 1-column cache eviction, RegexDialog header auto-detection, and isolated Worker process execution.
