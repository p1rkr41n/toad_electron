# Toad v2.1.6: Footprint Optimization & Fast Ingestion

**Release Date:** 2026-11-01  
**Publisher:** HelloKittyXamKinLung Standard  

---

### Key Highlights & Summary

The TOAD v2.1.6 release focuses on package footprint optimization, dead-code elimination, and accelerated ingestion pipelines.

#### 1. Binary & app.asar Footprint Optimization
- **75% Size Reduction:** Reduced `app.asar` footprint from 163 MB to under 30 MB via targeted webpack tree-shaking and asset pruning.
- **Dead Dependency Stripping:** Completely purged unused BigQuery SDK dependencies and `.map` sourcemap files from production packages.
- **Engine Preservation:** Ensured zero regression for native bindings (`duckdb.node`) and internal utility packages.

#### 2. Fast Ingestion & Dual-Engine Architecture
- **Dual DuckDB Engine:** Isolated UI query execution from background ingestion pipelines to guarantee responsive UI interactions (< 50ms) during large dataset processing.
- **First-Page Micro-Cache:** In-memory caching for the initial 1,000 rows enables instant table opens (< 2ms).
