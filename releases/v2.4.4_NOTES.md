# Toad v2.4.4 Release Notes

## English UI Standardization, Full Absolute Path Tooltips, Distinct Loading Status & Delete All Projects

### Overview
Toad v2.4.4 delivers international English UI standardization, ergonomic full-path tooltips, fine-grained file ingestion loading feedback, and a comprehensive project reset and cache purging engine:

1. **100% English UI Standardization**:
   - Table columns in `ProjectFilesTable.tsx` standardized to 4 concise titles:
     - `Name`
     - `DirPath`
     - `Size`
     - `Status`
   - Filter placeholders: `Filter name...`, `Filter dir...`, `Filter size...`, `Filter status...`.
   - Sort tooltips: `Sort by Name`, `Sort by DirPath`, `Sort by Size`, `Sort by Status`.
   - Empty state message: `No files matching filter` / `No projects available`.
   - All sidebar menus, hover cards, confirmation dialogs, and notifications converted to 100% standardized English with zero Vietnamese characters remaining.

2. **Full Absolute Path Tooltips on Hover**:
   - Hovering any row or file name cell displays the complete, disk-resolved absolute file path (`title={f.filePath}` e.g. `D:\Shared_UserData\Downloads\tad\data_sample\Security.evtx`).
   - Hovering the `DirPath` column displays the full parent directory path on disk (`title={getFullParentDir(f.filePath)}` e.g. `D:\Shared_UserData\Downloads\tad\data_sample`).
   - Monospace formatted `Full Path:` display inside the rich hover card.

3. **Distinctive Loading In Progress State**:
   - Files actively ingesting (`status === "PROCESSING"` / `isProcessing`) now display a distinct primary blue Blueprint `<Spinner size={11} intent={Intent.PRIMARY} />` alongside live percentage completion (`45%`).
   - Loading in progress is clearly distinguished from ready files (🟢 `READY`), uningested files (◌ `PENDING`), modified source files (🔴 `MODIFIED`), and failed files (! `ERROR`).
   - Live percentage progress updates dynamically in both `ProjectFilesTable` and `DataSourceSidebar` list nodes.

4. **Delete All Projects & Ledger Reset**:
   - Added danger `trash` button on the `PROJECTS` header toolbar next to `+`, `refresh`, and `clean`.
   - Two-step confirmation dialog protects against accidental destruction:
     *"Are you sure you want to delete all projects? This will reset the Parquet Ledger to 0 rows, permanently purge all temporary cache directories, and recreate a clean Untitled-1 default project."*
   - Invokes `pwManager.deleteAllProjects()` $\rightarrow$ IPC `project:deleteAll` $\rightarrow$ `ToadParquetLedger.deleteAllProjectsCascade()`:
     1. Drops DuckDB views to release Parquet file locks.
     2. Purges all temporary project subdirectories and caches in `temp/`.
     3. Truncates and resets `toad_ledger.parquet` to a clean 0-row Parquet file.
     4. Wipes in-memory cache and project registry.
     5. Automatically recreates default `Untitled-1` project with a fresh 5-character ID after 500ms debounce.

5. **Deep Integration QA SUITE KK**:
   - Added `SUITE KK` (KK.1 through KK.7) to `tests/deep_integration_qa.js`.
   - Validates concise column headers, full path tooltip resolution, forensic zero-Vietnamese text audit, cascade deletion engine with DuckDB 0-row parquet verification and 500ms auto-recovery, IPC integration, processing state spinner and percentage distinction, and system-wide version synchronization.
