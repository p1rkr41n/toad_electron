### Key Highlights & Summary

TOAD v2.5.0.3 delivers enhanced Windows Event Log (EVTX) parsing accuracy, microsecond-precision ISO-8601 timestamp standardization, and complete DuckDB schema parity for digital forensics and security log analysis.

#### 1. EVTX Hybrid Ingestion & Multi-Attribute Extraction
- **Zero Attribute Loss:** Refactored native Rust EVTX parser (`toad-core-rust`) with a multi-attribute extraction algorithm that accurately maps `param1`, `param2`, `param3`, and `Binary` fields without collision or key dropping.
- **Hybrid Forensic Querying:** Retains structured JSON in `EventData` alongside full record context in `RawEvent`, enabling instant SQL filtering on extracted columns while preserving raw event payloads.

#### 2. ISO-8601 Microsecond Timestamp Standardization
- **Precise 6-Digit Microseconds:** Standardized `TimeCreated` formatting to `YYYY-MM-DDTHH:MM:SS.ffffffZ` (`to_rfc3339_opts(SecondsFormat::Micros, true)`).
- **DuckDB Type Stability:** Eliminates timestamp inference degradation, guaranteeing DuckDB recognizes `TimeCreated` as a native `TIMESTAMP` across all event streams.

#### 3. Schema Parity & Numeric Casting
- **Consistent Record IDs:** Standardized `EventRecordID` and `EventID` to 64-bit integers (`BIGINT`) across both the high-speed Rust parser and fallback pipelines.
- **Qualifier & `#text` Handling:** Robustly parses complex XML attribute structures and numeric event qualifiers without schema drift.

#### 4. Footprint & Packaging Integrity
- **Optimized Binary Size:** Portable executable packaged at ~72.4 MB with `app.asar` footprint under 29 MB.
- **Zero-Duplicate Policy:** Strict deduplication enforced across release artifacts and local development binaries.
