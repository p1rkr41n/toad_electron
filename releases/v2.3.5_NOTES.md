## Toad v2.3.5 - Session Auto-Restore, Modified Red Status & Orphan Purge Release

### 🌟 Key Enhancements & Fixes

1. **Session Auto-Restore**:
   - **Persistent Workspace Restoration**: Toad now automatically remembers the last opened workspace folder (`last_directory` in `config.ini [general]`) and restores it seamlessly on startup.
   - **Zero Empty Black Sidebar**: Users will never encounter an empty black sidebar upon relaunching; the directory tree and previously ingested datasets are immediately ready.
   - Configurable via `auto_restore_last_directory = true` (default) in `config.ini`.

2. **Double-Valid Parquet Ledger: Modified Red Status (`#ef4444`)**:
   - **4-Tier Status Precision**: Standardized cache validity into `"VALID"`, `"MODIFIED"`, `"CORRUPTED"`, and `"UNPROCESSED"`.
   - **Vibrant Visual Alerts**: When an external source file has altered timestamps (`mtime`) or altered byte size, the sidebar displays vibrant red font (`#ef4444`) accompanied by an explicit `MODIFIED` badge.
   - **1-Click Auto Re-ingestion**: Clicking a modified file triggers priority streaming re-ingestion with `forceReopen: true`, seamlessly updating both DuckDB VIEWs and the State Ledger journal.

3. **Startup Orphan Temp Purge**:
   - **Zero Disk Waste from Crashes**: Automatically sweeps and purges stranded partial temporary files (`*.tmp_*.parquet` and `*.tmp`) left behind by unexpected crashes during 40GB+ stress runs.
   - **Strict Cache & Ledger Protection**: 100% isolates and preserves valid cache files (`*_cached_*.parquet`) and the immutable State Ledger (`toad_ledger.parquet`).

4. **100% Automated QA Test Coverage**:
   - All 149 deep integration tests passing across Suites A through FF with 0 regressions.
   - Added **SUITE FF** covering Session Auto-Restore config persistence, Double-Valid Modified detection, UI red styling compliance, orphan purge safety, and version synchronization.
