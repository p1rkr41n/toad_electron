### Key Highlights & Summary

TOAD v2.5.0.5 introduces recursive leaf extraction for deeply nested JSON and Windows Event Log (EVTX) objects, integrates DuckDB quoted JSONPath syntax (`$.Event.System.EventID."#text"`), enables two-phase dynamic Parquet auto-flattening for direct file ingestion, and adds an interactive Deep Scan (1,000 rows) schema discovery control in the Parse Columns dialog.

#### 1. Recursive Nested JSON Leaf Extraction (`RegexDialog.tsx` & `NestedJsonTraverser.ts`)
- **Deep Object Traversal:** Recursively traverses complex and multi-tier nested objects down to primitive leaves (strings, numbers, booleans) and arrays.
- **EVTX & Security Log Schema Parity:** Automatically surfaces all leaf fields (such as `Event.System.EventID.#text`, `Event.System.Provider.#attributes.Name`, `Event.EventData.param1`, `Event.EventData.Binary`) without manual schema mapping.
- **Quoted DuckDB JSONPath:** Automatically generates safe, quoted JSONPath expressions for DuckDB `json_extract_string`, preventing syntax or binder errors on special characters (`#text`, `#attributes`, `@xmlns`, dots, and spaces).

#### 2. Direct Ingestion Two-Phase Dynamic Auto-Flattening (`csvimport.ts` & `JsonStreamingFlattener.ts`)
- **Phase 1 (Introspect):** Introspects incoming `.json` / `.jsonl` schemas via `DESCRIBE` to detect nested `STRUCT` column hierarchies.
- **Phase 2 (Dynamic Unpack):** Automatically constructs dynamic projections to unpack nested struct attributes into clean, dot-notated columnar Parquet fields (`Event.System.EventID.#text`).
- **Native Parquet Speed:** Ingests and auto-flattens 57,000+ events in 430ms with 95.3% Parquet compression ratio.

#### 3. Deep Scan (1,000 Rows) Schema Discovery & Interactive Table
- **Sliding Window Extension:** Added a 1-click `Deep Scan (1,000 rows)` button in the Parse Columns dialog powered by chunked timesliced `SampleScanWorker`.
- **Interactive Management:** `NestedFieldsTable` supports real-time filtering, column sorting, type overriding, fill-rate metering, and in-place renaming before view creation.

#### 4. Footprint & Single-Binary Integrity
- **Optimized Size:** Portable binary packaged at ~72.37 MB with `app.asar` footprint at 28.15 MB (well under 45 MB budget).
- **Zero-Duplicate Policy:** Strict deduplication enforced across release artifacts and local development binaries.
