Toad Quick Start Guide v2.3.0

The Lightning-Fast Tabular Data Viewer & Pivot Table Analyzer powered by DuckDB & Rust SIMD

1. Welcome to Toad

Toad is a high-performance, lightweight desktop tool for opening, querying, exploring, and pivoting massive tabular datasets with sub-second responsiveness.

Toad natively supports all common columnar, text, log, and database formats:

Format Extensions Capabilities
Delimited Text .csv, .tsv, .txt High-speed multi-threaded ingestion with 3-tier fallback parser.
Apache Parquet .parquet Direct columnar scanning with zero conversion overhead.
DuckDB Database .duckdb Hierarchical SQL database tree and instant table views.
SQLite Database .sqlite, .db Full relational table and view exploration.
JSON / JSON Lines .json, .jsonl, .ndjson Streaming JSON parser into columnar fields.
Windows Event Logs .evtx Rust-accelerated EVTX decoding into structured records.
Raw Event Logs .log Ingests unformatted text lines directly into a raw_event column.
Toad Workspaces .tad Saves and restores pivot configurations, column views, and filters.

2. Launching Toad

  1. Desktop Executable: Double-click Toad.exe. Use File → Open to browse for data files.
  2. Explorer Integration & Drag & Drop: Right-click any supported file in Windows Explorer → Open With... → Toad, or simply drag and drop files onto an active Toad window.
  3. Command Line Interface (CLI): 
    $ toad dataset.csv
$ toad -f --show-queries server_logs.parquet

3. Exploring Tabular Data with Pivot Tables

A Toad pivot table transforms a flat table into an interactive hierarchical tree table by grouping rows that share identical values across selected Pivot Columns, and computing aggregations (sum, average, min, max, unique count) for numeric and textual columns.

To open the pivot panel, click the Pivot icon on the left ActivityBar:

This opens the Columns & Pivot sidebar:

Key Controls:

  • Pivot Checkbox: Select columns to form the hierarchical grouping tree (e.g. country → director).
  • Show Checkbox: Show or hide individual or all columns.
  • Sort Checkbox: Add multi-column sorting keys.
  • Pivot Tree Leaf Level: Choose which column acts as the lowest-level detail row at the bottom of the sidebar.

4. Column Management, Staged Changes & Push to Top v1.2.5

  • Icon-Only Action Toolbar: Features minimalist icon buttons: Realtime Sync (&9889; lightning), Revert (↶ undo), and Play (▶ play).
  • Realtime Sync Mode Toggle: Toggle live execution on or off. When Realtime is enabled (active amber glow), all column modifications (Show, Pivot, Sort, Push to Top) apply immediately to the table without needing Play. When disabled, Staged mode takes over.
  • Search & Jump-to-Select Column (Non-Filtering): Type in the search box to find any column by name. Toad instantly scrolls the list directly to the matching row and selects it with a prominent highlight—without hiding or filtering out any other columns! Press Enter to cycle through multiple matches.
  • Multi-Column Push to Top in Selection Order (Top Column): Each column row includes a dedicated Top button (↑). You can select multiple columns to push up together at the same time. Each chosen column displays its queue order (e.g. ↑ 1, ↑ 2, ↑ 3). Columns are pushed to the top in the exact sequence they were clicked (for example, selecting A, C, B, D places them as the first 4 columns). The columns are not rearranged immediately—they are pushed to the top only after clicking the Play button!
  • Tab Change Auto-Revert: In Staged mode, if you click away to another tab (in Additional Properties, ActivityBar, or another file) or click Revert without pressing Play, the staged Columns state is automatically restored to match the main table.
  • Table-Order Synchronized Sequence: The Columns sidebar matches the exact visual display sequence of columns in the main table grid.
  • Sort Mode Toggle: Click the Column header to toggle between Table Order and Alphabetical (A-Z).
  • Inline Double-Click Renaming: Double-click any column name in the Columns sidebar to rename it directly! Press Enter to save or Escape to cancel.

5. Searchable Compound Filtering & Drag-and-Drop Reordering v1.2.7

Click the Filter button in the bottom footer to expand the compound query editor.

  • Drag-and-Drop Condition Reordering: Grab the vertical drag handle (⋮⋮) at the start of any filter row to drag it up or down to reorder conditions within the group.
  • Drag Into / Out of Groups (Nesting & Unnesting): Easily drag filter conditions into child groups (nesting into sub-group logic) or pull them out of groups into the parent group or root level. No need to delete and recreate rules from scratch!
  • Quick-Action Navigation Buttons: Each condition row provides one-click action buttons: Move Up (↑), Move Down (↓), and Move Out (←) for instant accessibility.
  • Sub-Group Header Controls: Nested filter groups also feature dedicated move buttons (Up, Down, Move Out) to reorganize whole logical blocks at once.
  • Searchable Column Autocomplete: Type any substring in the column box to instantly locate columns across tables with 100+ fields.
  • Resizable Panel: Drag the top handle to resize the filter pane, or double-click it to toggle maximize.
  • Rich Operators: Numeric (=, !=, <, >, <=, >=), Textual (CONTAINS, STARTS WITH, ENDS WITH), Sets (IN, NOT IN), and Null checks (IS NULL, IS NOT NULL).
  • Nested Logic Trees: Freely nest clauses with AND or OR operators to build sophisticated queries.

Extract structured data fields from complex semi-structured logs (Windows Event Logs, SIEM, JSON, Key-Value, Syslog) with sub-second SQL compilation:

  • Unified "Parse" Identity: Access via the Parse button in the footer or left ActivityBar.
  • Linear-Style Capsule Segmented Switch: Effortlessly switch between Visual Mode (⚡ Visual) for auto-detection and Regex Mode (</> Regex) for custom expressions.
  • 1-Click Quick Delimiter Preset Chips: Instant 1-click selection chips for common separators (Space, ,, |, ¦, ;, Tab) eliminating manual typing.
  • Visual Smart Coalescing Indicator: Automatically displays a distinctive 🔗 COALESCE badge when multiple fields are mapped to the same target column name.
  • Dynamic Action Button: Clear affordance showing exactly how many columns will be applied: Apply (N Columns).
  • Heterogeneous Multi-Row Key Discovery: Scans across multiple sample rows (50+ events) to discover all unique keys with accurate Fill Rate % indicators.
  • Universal Positional Token Fallback (strX): Any unkeyed or unrecognized tokens are automatically captured into non-repeating positional columns: str1, str2, str3...
  • Auto-Pruned Fallback Column (unmatched_[column]): Preserves full raw text for irregular log lines or noise. If 100% of rows match cleanly, the fallback column is automatically pruned (0 empty columns).
  • 1,000 Rows Test & Match Rate Inspector: Test-parse 1,000 rows in < 5ms with visual match-rate bars, quick copy buttons, and inspect corrupt lines before committing.

7. Zero-Cost Instant Column Reordering v2.0.5

Reorder, swap, or push columns to top instantly without UI freeze:

  • Sub-5ms Column Swapping: Swapping or dragging giant text columns (even with millions of characters) executes in < 5 ms.
  • IPC & Query Short-Circuit: Reordering columns updates visual DOM indices directly in SlickGrid while completely bypassing DuckDB re-queries and avoiding multi-megabyte IPC serializations.
  • Strict CSS Virtual Containment: Cell containment (contain: strict) isolates layout calculations from the main document, ensuring 60 FPS scrolling responsiveness.

8. Dual DuckDB Engine Pipeline & Architecture Dual DuckDB + Rust SIMD

Toad v2.0.5 achieves breakthrough responsiveness over gigabyte-scale datasets through its isolated Dual DuckDB Engine Architecture:

  1. Interactive UI Engine (db_ui): Dedicated exclusively to high-speed DataGrid rendering, filtering, sorting, and pivoting. Maintained with reserved CPU threads (2 cores), ensuring sub-50ms query responses even while multi-gigabyte files process in the background.
  2. Background Ingestion Engine (db_ingest): Operates as a completely separate in-memory database instance (:memory:ingest) executing heavy CPU-saturating Parquet conversions, calculations, and EVTX decoding without blocking the UI.
  3. RAM First-Page Micro-Cache: Instantaneous retrieval of the first 1,000 rows in < 2 ms with 0 disk I/O.
  4. Instant Zero-Copy Parquet VIEW Mount: Mounts physical Parquet files directly via virtual views in < 5 ms.
  5. Intelligent Queue Scheduling (SJF & VIP Priority): Prioritizes smaller files first (Shortest Job First) and allows instant user-click preemption (VIP Priority Jump).
